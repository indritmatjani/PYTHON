# 🐍 Python

Raccolta di esercizi e progetti in Python: il percorso **CS50**, esercizi universitari e piccoli progetti per fare pratica.

## 📁 Contenuto

| Cartella | Descrizione |
|---|---|
| [`CS50/`](CS50/) | Esercizi del corso Harvard CS50 (es. `itunes.py`, `generate.py`, `name.py`) |
| [`UNIVERSITA/`](UNIVERSITA/) | Esercizi universitari: ricerca binaria e lineare, ricorsione, liste concatenate, numeri primi, fattoriale, tavola pitagorica, equazioni di 2° grado e altro |
| [`Random_projects_for_learning/`](Random_projects_for_learning/) | Mini-progetti: indovina il numero, quiz, sasso-carta-forbici |

## 🚀 Come eseguire

Ogni file è indipendente e richiede **Python 3**:

```bash
python3 CS50/itunes.py
```

## 🎯 Scopo

Un archivio personale di pratica: dalle basi della programmazione fino ad algoritmi e strutture dati.
